# Realtime (WebSocket Gateway)

Pasta reservada para o Gateway WebSocket (rastreamento GPS em tempo real, alertas,
replanejamento de rota). Nesta etapa, propositalmente vazia — nenhum evento ou
regra de negocio foi implementado. O Gateway sera adicionado como um modulo Nest
proprio (`realtime.module.ts`, `realtime.gateway.ts`) quando a funcionalidade de
rastreamento em tempo real for desenvolvida.
