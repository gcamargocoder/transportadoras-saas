# @transportadoras/types

Interfaces, DTOs e tipos TypeScript compartilhados entre `admin-web`, `driver-app` e `api`.

Mantido vazio nesta etapa (fundacao do projeto). Cada modulo de negocio (viagens,
pedagios, veiculos, tenants, usuarios...) adiciona seus tipos aqui conforme e implementado,
evitando duplicacao entre frontend e backend.
